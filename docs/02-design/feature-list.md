## 1. โปรไฟล์และไทม์ไลน์แคมป์

ตั้งค่าตัวนักมวยและไฟต์ที่กำลังเตรียม จากนั้นระบบคำนวณเองว่าตอนนี้อยู่ช่วงใดของแคมป์ ซึ่งเป็นบริบท
ที่ทุกฟีเจอร์อื่นใช้แปลผล — คะแนนเดียวกันมีความหมายต่างกันในช่วง Build กับสัปดาห์ชก

- รหัสที่ครอบคลุม: FR-01, FR-02, FR-03, FR-04 → [[20260828-01-boxer-recovery-tracking#3.1 โปรไฟล์และไทม์ไลน์แคมป์|spec §3.1]]
- บทบาทผู้ใช้: นักมวย
- ระดับความสำคัญ (MoSCoW): Must have

**ช่วงแคมป์ที่ระบบรู้จัก:** Off-camp → Build → Sharpen → Weight cut → Weigh-in→Fight → Post-fight

## 2. เชื่อมต่ออุปกรณ์และ baseline ส่วนบุคคล

ข้อมูลที่เก็บได้ฟรีและไม่ต้องกรอกเลย มาจากอุปกรณ์ที่นักมวยใส่อยู่แล้ว ระบบใช้ 14 วันแรกสร้างค่าอ้างอิง
ของคนคนนั้น เพราะค่าปกติของนักมวยแต่ละคนต่างกันมากจนใช้ค่ามาตรฐานประชากรไม่ได้

- รหัสที่ครอบคลุม: FR-05, FR-06 → [[20260828-01-boxer-recovery-tracking#3.2 การเชื่อมต่ออุปกรณ์และ baseline|spec §3.2]]
- บทบาทผู้ใช้: นักมวย
- ระดับความสำคัญ (MoSCoW): Must have

## 3. บันทึกการซ้อม 4 สกุลโหลด

หัวใจของฟีเจอร์นี้คือ **สปาร์ริงถูกนับเป็นหน่วยโหลดของตัวเอง** ไม่รวมกับโหลดซ้อมอื่น เพราะกล้ามเนื้อ
ฟื้นภายในไม่กี่วันแต่สมองใช้เวลาเป็นสัปดาห์ ถ้ารวมกันจะกลบสิ่งที่สำคัญที่สุด

- รหัสที่ครอบคลุม: FR-07, FR-08, FR-09, FR-10, FR-11 → [[20260828-01-boxer-recovery-tracking#3.3 การบันทึกการซ้อม|spec §3.3]]
- บทบาทผู้ใช้: นักมวย
- ระดับความสำคัญ (MoSCoW): Must have

## 4. ภาระที่ศีรษะและการทดสอบระบบประสาท

ฟีเจอร์ที่ทำให้ระบบนี้เป็นระบบสำหรับมวยโดยเฉพาะ รวมทั้งการติดตามอาการ การทดสอบเชิงวัตถุวิสัย
และคำเตือนเมื่อเข้าเกณฑ์ — โดยยึด NFR-04 เป็นกรอบเสมอ คือ **ติดตามและแจ้ง ไม่วินิจฉัย**

- รหัสที่ครอบคลุม: FR-12, FR-13, FR-14, FR-15 → [[20260828-01-boxer-recovery-tracking#3.4 อาการที่ศีรษะและการทดสอบ|spec §3.4]] · FR-26 → [[20260828-01-boxer-recovery-tracking#3.6 คะแนนและ limiting factor|spec §3.6]] · NFR-04 → [[20260828-01-boxer-recovery-tracking#4. ความต้องการที่ไม่ใช่เชิงฟังก์ชัน|spec §4]]
- บทบาทผู้ใช้: นักมวย
- ระดับความสำคัญ (MoSCoW): Must have

> **หมายเหตุการจัดกลุ่ม:** FR-26 อยู่ใต้หัวข้อ §3.6 ในเอกสาร spec แต่จัดไว้ในฟีเจอร์นี้ เพราะในมุมของ
> ผู้ออกแบบและผู้พัฒนา คำเตือนเรื่องศีรษะเป็นส่วนหนึ่งของฟีเจอร์ภาระที่ศีรษะ ไม่ใช่ของกลไกคะแนน

## 5. พลังงาน อาหาร และการทำน้ำหนัก

รวมสามเรื่องไว้เป็นฟีเจอร์เดียวเพราะในกีฬามวยมันคือคันโยกเดียวกันที่ถูกดึงไปคนละทาง — ต้องกินให้พอ
ฟื้นตัวแต่ต้องลดน้ำหนักไปพร้อมกัน ระบบมีหน้าที่บริหารความขัดแย้งนี้ ไม่ใช่แกล้งทำเป็นว่าเป็นคนละเรื่อง

- รหัสที่ครอบคลุม: FR-16, FR-17, FR-18, FR-19, FR-20, FR-21 → [[20260828-01-boxer-recovery-tracking#3.5 พลังงาน อาหาร และน้ำหนัก|spec §3.5]] · NFR-05 → [[20260828-01-boxer-recovery-tracking#4. ความต้องการที่ไม่ใช่เชิงฟังก์ชัน|spec §4]]
- บทบาทผู้ใช้: นักมวย
- ระดับความสำคัญ (MoSCoW): Must have

## 6. คะแนน 6 หมวดและ limiting factor ประจำวัน

ฟีเจอร์ที่ให้คำตอบที่นักมวยเปิดแอปมาเพื่อดู: วันนี้อะไรคือเพดาน และซ้อมอะไรได้บ้าง จุดสำคัญคือระบบ
รายงาน **หมวดที่ต่ำที่สุด** ไม่ใช่ค่าเฉลี่ย และเมนูการซ้อมต้องบอกว่าทำอะไร**ได้** ไม่ใช่แค่บอกให้พัก

- รหัสที่ครอบคลุม: FR-22, FR-23, FR-24, FR-25, FR-27 → [[20260828-01-boxer-recovery-tracking#3.6 คะแนนและ limiting factor|spec §3.6]] · NFR-08 → [[20260828-01-boxer-recovery-tracking#4. ความต้องการที่ไม่ใช่เชิงฟังก์ชัน|spec §4]]
- บทบาทผู้ใช้: นักมวย
- ระดับความสำคัญ (MoSCoW): Must have

## 7. โปรโตคอลฟื้นตัวและวงจรตรวจสอบย้อนกลับ

เสนอสิ่งที่ควรทำเพียงหนึ่งอย่างต่อวันตาม limiting factor แล้ววัดผลย้อนกลับในวันถัดไป วงจรนี้คือส่วนที่
ทำให้ระบบฉลาดขึ้นเฉพาะกับนักมวยคนนั้น และเป็นส่วนที่คู่แข่งลอกไม่ได้ด้วยการซื้อฮาร์ดแวร์

- รหัสที่ครอบคลุม: FR-28, FR-29, FR-30, FR-31 → [[20260828-01-boxer-recovery-tracking#3.7 โปรโตคอลและวงจรตรวจสอบย้อนกลับ|spec §3.7]]
- บทบาทผู้ใช้: นักมวย
- ระดับความสำคัญ (MoSCoW): Must have

## 8. สรุปรายสัปดาห์และการส่งออกข้อมูล

ภาพรวมย้อนหลังสำหรับทบทวนกับตัวเองหรือกับโค้ช ไม่ใช่ส่วนที่ใช้ทุกวัน จึงเลื่อนออกจาก MVP ได้

- รหัสที่ครอบคลุม: FR-32, FR-33 → [[20260828-01-boxer-recovery-tracking#3.8 สรุปและการส่งออก|spec §3.8]]

- ระดับความสำคัญ (MoSCoW): Should have
