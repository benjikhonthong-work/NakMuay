## 1. โปรไฟล์และไทม์ไลน์แคมป์

#### FR-01 (สูง) — สร้างโปรไฟล์นักมวย
- **AC-1** — Given ผู้ใช้เปิดแอปครั้งแรก When กรอกชื่อ เพศ วันเกิด ส่วนสูง และพิกัดน้ำหนักครบถ้วน แล้วกดบันทึก Then ระบบสร้างโปรไฟล์และพาไปหน้าสร้าง fight camp
- **AC-2** — Given ผู้ใช้อยู่หน้าสร้างโปรไฟล์ When เว้นช่องพิกัดน้ำหนักว่างไว้แล้วกดบันทึก Then ระบบไม่บันทึกและแสดงข้อความระบุว่าช่องใดยังขาด

#### FR-02 (สูง) — สร้าง fight camp
- **AC-1** — Given มีโปรไฟล์แล้ว When ระบุวันชก วันชั่งน้ำหนัก และพิกัดน้ำหนักของไฟต์นั้น Then ระบบบันทึกแคมป์และแสดงจำนวนวันที่เหลือถึงวันชก
- **AC-2** — Given ผู้ใช้กำลังสร้างแคมป์ When ระบุวันชั่งน้ำหนักหลังวันชก Then ระบบไม่บันทึกและแจ้งว่าวันชั่งน้ำหนักต้องอยู่ก่อนวันชก

#### FR-03 (สูง) — คำนวณช่วงแคมป์อัตโนมัติ
- **AC-1** — Given แคมป์มีวันชกที่กำหนดแล้ว When ผู้ใช้เปิดหน้าใดก็ตามในแอป Then ระบบแสดงชื่อช่วงแคมป์ปัจจุบันหนึ่งในหกค่า (Off-camp, Build, Sharpen, Weight cut, Weigh-in→Fight, Post-fight)
- **AC-2** — Given เหลือไม่เกิน 10 วันถึงวันชั่งน้ำหนัก When ผู้ใช้เปิดแอป Then ช่วงแคมป์ที่แสดงคือ Weight cut โดยผู้ใช้ไม่ต้องสลับโหมดเอง
- **AC-3** — Given ชั่งน้ำหนักผ่านแล้วและยังไม่ถึงเวลาขึ้นชก When ผู้ใช้เปิดแอป Then ช่วงแคมป์ที่แสดงคือ Weigh-in→Fight

#### FR-04 (กลาง) — แก้ไขหรือเลื่อนวันชก
- **AC-1** — Given แคมป์อยู่ในช่วง Build When ผู้ใช้เลื่อนวันชกออกไป 3 สัปดาห์ Then ระบบคำนวณช่วงแคมป์ทั้งหมดใหม่และแสดงสรุปว่าช่วงใดเปลี่ยนไปอย่างไร

## 2. เชื่อมต่ออุปกรณ์และ baseline ส่วนบุคคล

#### FR-05 (สูง) — เชื่อมต่ออุปกรณ์สวมใส่
- **AC-1** — Given ผู้ใช้อนุญาตให้เข้าถึงข้อมูลสุขภาพจากอุปกรณ์แล้ว When เปิดแอปในตอนเช้า Then ระบบแสดง HRV ชีพจรขณะพัก และข้อมูลการนอนของคืนที่ผ่านมา โดยผู้ใช้ไม่ต้องกรอกค่าใดเลย
- **AC-2** — Given อุปกรณ์ยังไม่ซิงก์ข้อมูลของคืนที่ผ่านมา When ผู้ใช้เปิดแอป Then ระบบแสดงสถานะว่ายังไม่มีข้อมูลของคืนนี้ และไม่แสดงคะแนนหมวด Sleep & Heart แทนการเดาค่า

#### FR-06 (สูง) — สร้าง baseline เฉพาะบุคคล
- **AC-1** — Given ผู้ใช้ใช้งานมาแล้วน้อยกว่า 14 วัน When เปิดหน้าแรก Then ระบบแสดงสถานะ "กำลังเก็บ baseline" พร้อมจำนวนวันที่เหลือ และไม่แสดงคะแนน 6 หมวด
- **AC-2** — Given ผู้ใช้มีข้อมูลครบ 14 วันแล้ว When เปิดหน้าแรก Then ระบบเริ่มแสดงคะแนน 6 หมวดและ limiting factor
- **AC-3** — Given baseline ถูกสร้างแล้ว When ระบบเปรียบเทียบค่าปัจจุบัน Then ต้องเทียบกับ baseline ของผู้ใช้คนนั้นเอง ไม่ใช่ค่ามาตรฐานประชากร

## 3. บันทึกการซ้อม 4 สกุลโหลด

#### FR-07 (สูง) — บันทึกเซสชันซ้อม
- **AC-1** — Given ผู้ใช้อยู่หน้าบันทึกการซ้อม When เลือกสกุลโหลดหนึ่งใน 4 (สปาร์ริง / มวยเทคนิค / คาร์ดิโอ / ยกเวท) และระบุระยะเวลา แล้วบันทึก Then ระบบบันทึกเซสชันพร้อมวันเวลา
- **AC-2** — Given ผู้ใช้อยู่หน้าบันทึกการซ้อม When ไม่เลือกสกุลโหลดแล้วกดบันทึก Then ระบบไม่บันทึกและแจ้งว่าต้องเลือกประเภทการซ้อมก่อน

#### FR-08 (สูง) — บันทึกรายละเอียดสปาร์ริง
- **AC-1** — Given ผู้ใช้เลือกสกุลโหลด "สปาร์ริง" When ระบุจำนวนยกและระดับความหนัก (เบา / กลาง / หนัก) Then ระบบบันทึกทั้งสองค่าและนำไปรวมในยอดสะสมสปาร์ริง
- **AC-2** — Given ผู้ใช้เลือก "สปาร์ริง" When ไม่ระบุจำนวนยกแล้วกดบันทึก Then ระบบไม่บันทึกและแจ้งว่าจำนวนยกเป็นข้อมูลที่จำเป็นสำหรับสปาร์ริง

#### FR-09 (สูง) — บันทึกรายละเอียดยกเวท
- **AC-1** — Given ผู้ใช้เลือกสกุลโหลด "ยกเวท" When ระบุส่วนของร่างกาย (บน / ล่าง / ทั้งตัว) ระยะเวลา และความหนัก Then ระบบบันทึกครบทั้งสามค่า

#### FR-10 (สูง) — สะสมภาระสปาร์ริงแยกจากโหลดอื่น
- **AC-1** — Given ผู้ใช้มีทั้งเซสชันสปาร์ริงและเซสชันยกเวทในรอบ 7 วัน When ระบบคำนวณยอดสะสมสปาร์ริง Then ยอดที่ได้ต้องนับเฉพาะเซสชันสปาร์ริงเท่านั้น ไม่รวมสกุลโหลดอื่น
- **AC-2** — Given มีข้อมูลย้อนหลังมากกว่า 28 วัน When ผู้ใช้เปิดดูภาระสปาร์ริง Then ระบบแสดงยอดสะสมทั้งหน้าต่าง 7 วันและ 28 วัน

#### FR-11 (สูง) — บันทึกจุดที่ปวดบนแผนที่ร่างกาย
- **AC-1** — Given ผู้ใช้บันทึกเซสชันเสร็จ When แตะจุดบนแผนที่ร่างกายและเลือกระดับความปวด Then ระบบบันทึกทั้งตำแหน่งและระดับ
- **AC-2** — Given ผู้ใช้อยู่หน้าแผนที่ร่างกาย When ตรวจจุดที่เลือกได้ Then ต้องมีอย่างน้อย: มือ/ข้อมือ ไหล่ คอ หลังล่าง สะโพก น่อง

## 4. ภาระที่ศีรษะและการทดสอบระบบประสาท

#### FR-12 (สูง) — checklist อาการหลังรับแรงกระแทก
- **AC-1** — Given ผู้ใช้อยู่ในขั้นตอนเช็กอินตอนเช้า When เปิด checklist อาการ Then ต้องมีตัวเลือกอย่างน้อย: ปวดศีรษะ ตาพร่า ไวต่อแสง มึนงง คลื่นไส้ นอนไม่หลับ อารมณ์แปรปรวน
- **AC-2** — Given ผู้ใช้ไม่มีอาการใดเลย When กดปุ่ม "ไม่มีอาการ" Then ระบบบันทึกผลว่าไม่มีอาการและไปขั้นตอนถัดไปโดยไม่ต้องแตะรายการทีละข้อ

#### FR-13 (สูง) — ทดสอบเวลาตอบสนอง
- **AC-1** — Given ผู้ใช้เริ่มการทดสอบเวลาตอบสนอง When ทำการทดสอบจนจบ Then การทดสอบใช้เวลาไม่เกิน 30 วินาที และระบบแสดงผลเทียบกับ baseline ของผู้ใช้เอง
- **AC-2** — Given ผู้ใช้ยังไม่มี baseline ของการทดสอบนี้ When ทำการทดสอบครั้งแรก Then ระบบบันทึกผลไว้เป็นข้อมูลสร้าง baseline และแจ้งว่ายังเทียบผลไม่ได้

#### FR-14 (สูง) — ทดสอบความสดด้วยการนับหมัด
- **AC-1** — Given ผู้ใช้เริ่มการทดสอบนับหมัด When ครบ 10 วินาที Then ระบบหยุดนับเองและแสดงผลเป็นร้อยละเทียบกับสถิติดีที่สุดของผู้ใช้เอง
- **AC-2** — Given ผลการทดสอบต่ำกว่าสถิติดีที่สุดเกิน 10 เปอร์เซ็นต์ When ระบบคำนวณคะแนน Then คะแนนหมวด Power & Speed ต้องลดลงจากระดับของวันก่อนหน้า

#### FR-15 (ต่ำ) — ทดสอบการทรงตัว
- **AC-1** — Given ผู้ใช้เริ่มการทดสอบการทรงตัว When ยืนขาเดียวหลับตาครบ 30 วินาที Then ระบบบันทึกค่าการแกว่งจากเซ็นเซอร์ของโทรศัพท์และแสดงผลเทียบ baseline

#### FR-26 (สูง) — เตือนภาระที่ศีรษะ
- **AC-1** — Given ผู้ใช้เลือกอาการตั้งแต่เกณฑ์ที่กำหนดขึ้นไป และยอดสะสมสปาร์ริง 7 วันเกินเกณฑ์ When ระบบประมวลผลเช็กอินตอนเช้า Then ระบบแสดงคำเตือนให้หยุดสปาร์ริงและไปพบแพทย์อย่างเด่นชัดก่อนเนื้อหาอื่น
- **AC-2** — Given ระบบแสดงคำเตือนภาระที่ศีรษะ When ตรวจสอบข้อความที่แสดง Then ข้อความต้องไม่ระบุชื่อภาวะหรือโรคใดๆ และต้องมีข้อความแนะนำให้พบแพทย์เสมอ
- **AC-3** — Given ระบบแสดงคำเตือนภาระที่ศีรษะ When ผู้ใช้เปิดเมนูการซ้อมของวันนั้น Then สกุลโหลด "สปาร์ริง" ต้องมีสถานะ "ควรงด"

#### NFR-04 (สูง) — ไม่วินิจฉัยโรค ใช้ถ้อยคำเชิงติดตาม
- **AC-1** — Given ระบบแสดงคำเตือนใดก็ตามในแอป When ตรวจสอบข้อความทั้งหมด Then ต้องไม่มีข้อความใดที่ระบุว่าผู้ใช้มีภาวะหรือโรคใด และทุกคำเตือนด้านสุขภาพต้องมีคำแนะนำให้ปรึกษาบุคลากรทางการแพทย์

## 5. พลังงาน อาหาร และการทำน้ำหนัก

#### FR-16 (สูง) — บันทึกน้ำหนักตอนเช้า
- **AC-1** — Given ผู้ใช้อยู่หน้าเช็กอินตอนเช้า When กรอกน้ำหนักแล้วบันทึก Then ระบบแสดงระยะห่างจากพิกัดน้ำหนักของแคมป์ปัจจุบันเป็นกิโลกรัม
- **AC-2** — Given ผู้ใช้มีข้อมูลน้ำหนักอย่างน้อย 7 วัน When เปิดหน้าน้ำหนัก Then ระบบแสดงกราฟแนวโน้มน้ำหนักย้อนหลัง

#### FR-17 (สูง) — บันทึกภาวะน้ำในร่างกาย
- **AC-1** — Given ผู้ใช้อยู่หน้าเช็กอินตอนเช้า When เลือกสีปัสสาวะจากชาร์ต Then ชาร์ตต้องมี 8 ระดับให้เลือก และระบบบันทึกค่าที่เลือก
- **AC-2** — Given ผู้ใช้เลือกสีปัสสาวะในระดับที่บ่งชี้ภาวะขาดน้ำ When ระบบประมวลผล Then คะแนนหมวด Fuel & Weight ต้องสะท้อนค่านี้ และแสดงเหตุผลเมื่อผู้ใช้กดดูที่มาของคะแนน

#### FR-18 (สูง) — บันทึกอาหารแบบไม่นับแคลอรี่
- **AC-1** — Given ผู้ใช้อยู่หน้าบันทึกอาหาร When ตรวจสอบสิ่งที่ต้องกรอก Then ต้องมีเพียงสามคำถาม: กินหลังซ้อมแล้วหรือยัง, ได้โปรตีนครบสามมื้อหรือไม่, ระดับแป้งวันนี้ (น้อย / กลาง / มาก)
- **AC-2** — Given ผู้ใช้อยู่หน้าบันทึกอาหาร When มองหาช่องกรอกแคลอรี่หรือน้ำหนักอาหาร Then ต้องไม่มีช่องดังกล่าวในหน้าจอนี้

#### FR-19 (สูง) — เตือนเมื่อลดน้ำหนักเร็วเกินเกณฑ์
- **AC-1** — Given อัตราการลดน้ำหนักย้อนหลัง 7 วันเกินเกณฑ์ปลอดภัยที่กำหนดไว้ When ผู้ใช้บันทึกน้ำหนักตอนเช้า Then ระบบแสดงคำเตือนพร้อมข้อเสนอให้ชะลอการลด
- **AC-2** — Given ระบบแสดงคำเตือนอัตราการลดน้ำหนัก When ตรวจสอบเนื้อหาที่แสดง Then ต้องไม่มีคำแนะนำวิธีเร่งการลดน้ำหนักใดๆ ปรากฏอยู่

#### FR-20 (กลาง) — โหมดหลังชั่งน้ำหนัก
- **AC-1** — Given ผู้ใช้ยืนยันว่าชั่งน้ำหนักผ่านแล้ว When เปิดแอป Then ระบบเข้าสู่โหมดหลังชั่งและแสดงตัวนับถอยหลังการเติมน้ำและแป้งเป็นรายชั่วโมงจนถึงเวลาขึ้นชก
- **AC-2** — Given ระบบอยู่ในโหมดหลังชั่ง When ตรวจสอบหน้าจอ Then หน้าจอต้องแสดงเฉพาะการเติมน้ำและการเติมแป้งเท่านั้น ไม่แสดงคะแนน 6 หมวดหรือเมนูการซ้อม

#### FR-21 (ต่ำ) — บันทึกคาเฟอีนและแอลกอฮอล์
- **AC-1** — Given ผู้ใช้บันทึกคาเฟอีนพร้อมเวลาที่ดื่ม When ข้อมูลการนอนของคืนนั้นถูกซิงก์แล้ว Then ระบบแสดงความสัมพันธ์ระหว่างเวลาที่ดื่มกับคุณภาพการนอนของคืนนั้น

#### NFR-05 (สูง) — ไม่เสนอวิธีรีดน้ำหนัก และเตือนเมื่อเข้าใกล้เกณฑ์อันตราย
- **AC-1** — Given ผู้ใช้อยู่ในช่วง Weight cut When เปิดหน้าจอใดก็ตามที่เกี่ยวกับน้ำหนัก Then ระบบต้องไม่แสดงคำแนะนำวิธีรีดน้ำหนัก อบซาวน่า หรือจำกัดน้ำ
- **AC-2** — Given ผู้ใช้กำลังเข้าใกล้เกณฑ์อัตราการลดที่ไม่ปลอดภัย When ระบบประมวลผลน้ำหนักประจำวัน Then ระบบต้องเตือนล่วงหน้าก่อนถึงเกณฑ์ ไม่ใช่เตือนหลังเกินแล้วเท่านั้น

## 6. คะแนน 6 หมวดและ limiting factor ประจำวัน

#### FR-22 (สูง) — คำนวณคะแนน 6 หมวด
- **AC-1** — Given ผู้ใช้มี baseline แล้วและบันทึกข้อมูลของวันนี้ครบ When เปิดหน้าแรก Then ระบบแสดงคะแนนครบทั้ง 6 หมวด (Brain, Fuel & Weight, Sleep & Heart, Power & Speed, Body, Mind)
- **AC-2** — Given ระบบแสดงคะแนนหมวดใดก็ตาม When ตรวจสอบรูปแบบการแสดงผล Then ต้องแสดงเป็นระดับ 5 ขั้น ไม่ใช่ตัวเลข 0–100
- **AC-3** — Given ข้อมูลของหมวดใดหมวดหนึ่งขาดหายในวันนั้น When ระบบคำนวณคะแนน Then หมวดนั้นต้องแสดงสถานะ "ไม่มีข้อมูล" แทนการเดาค่า และต้องไม่ถูกนำไปคิดเป็น limiting factor

#### FR-23 (สูง) — ระบุ limiting factor ประจำวัน
- **AC-1** — Given คะแนน 6 หมวดของวันนี้คำนวณเสร็จแล้ว When เปิดหน้าแรก Then ระบบแสดงหมวดที่มีระดับต่ำที่สุดเป็น limiting factor ในรูปประโยคเดียวที่เด่นที่สุดบนหน้าจอ
- **AC-2** — Given หมวด Brain อยู่ระดับ 2 และหมวดอื่นทั้งหมดอยู่ระดับ 4 ขึ้นไป When ระบบระบุ limiting factor Then ต้องได้ Brain ไม่ใช่ค่าเฉลี่ยของทั้ง 6 หมวด
- **AC-3** — Given มีสองหมวดขึ้นไปที่อยู่ระดับต่ำสุดเท่ากัน When ระบบระบุ limiting factor Then ต้องแสดงทุกหมวดที่เสมอกัน ไม่ใช่เลือกมาเพียงหมวดเดียว

#### FR-24 (สูง) — แปลผลตามช่วงแคมป์
- **AC-1** — Given ค่า HRV ต่ำกว่า baseline ในระดับเดียวกัน When ระบบแปลผลในช่วง Build Then คะแนน Sleep & Heart อยู่ในระดับที่ยอมรับได้ พร้อมคำอธิบายว่าเป็นเรื่องปกติของช่วงสร้างโหลด
- **AC-2** — Given ค่า HRV ต่ำกว่า baseline ในระดับเดียวกันกับ AC-1 When ระบบแปลผลในช่วง Weigh-in→Fight Then คะแนน Sleep & Heart ต้องต่ำกว่ากรณี AC-1 และแสดงคำเตือน

#### FR-25 (สูง) — แสดงเมนูการซ้อมที่ทำได้วันนี้
- **AC-1** — Given คะแนนของวันนี้คำนวณเสร็จแล้ว When เปิดเมนูการซ้อม Then ระบบแสดงสถานะครบทั้ง 4 สกุลโหลด โดยแต่ละสกุลมีค่าใดค่าหนึ่งใน ทำได้ / ทำได้แบบจำกัด / ควรงด
- **AC-2** — Given limiting factor ของวันนี้คือ Brain When เปิดเมนูการซ้อม Then สปาร์ริงต้องมีสถานะ "ควรงด" ขณะที่ยกเวทยังมีสถานะ "ทำได้" เพราะยกเวทไม่ลงหมวด Brain
- **AC-3** — Given ระบบแสดงเมนูการซ้อม When ตรวจสอบแต่ละสกุลโหลด Then ทุกสกุลต้องมีข้อความเหตุผลกำกับสถานะของตนเอง

#### FR-27 (กลาง) — เตือนภาวะซ้อมเกิน
- **AC-1** — Given ค่า HRV ต่ำกว่า baseline ต่อเนื่องเกินเกณฑ์วันที่กำหนด พร้อมชีพจรขณะพักสูงขึ้น When ผู้ใช้เปิดแอป Then ระบบแสดงคำเตือนภาวะซ้อมเกินพร้อมระบุจำนวนวันที่ต่อเนื่อง

#### NFR-08 (กลาง) — ทุกคะแนนกดดูที่มาได้
- **AC-1** — Given ระบบแสดงคะแนนของหมวดใดก็ตาม When ผู้ใช้แตะที่คะแนนนั้น Then ระบบแสดงรายการปัจจัยที่ทำให้คะแนนขึ้นหรือลงในวันนั้น
- **AC-2** — Given ระบบไม่สามารถระบุปัจจัยที่ทำให้คะแนนเปลี่ยนได้ When จะแสดงคะแนนนั้น Then ต้องไม่แสดงคะแนน แต่แสดงสถานะ "ไม่มีข้อมูลเพียงพอ" แทน

## 7. โปรโตคอลฟื้นตัวและวงจรตรวจสอบย้อนกลับ

#### FR-28 (สูง) — เสนอโปรโตคอลฟื้นตัววันละหนึ่งอย่าง
- **AC-1** — Given ระบบระบุ limiting factor ของวันนี้แล้ว When ถึงช่วงเย็น Then ระบบเสนอโปรโตคอลที่ตรงกับหมวดนั้นพร้อมตัวจับเวลาในแอป
- **AC-2** — Given ระบบเสนอโปรโตคอลของวันนี้แล้ว When ผู้ใช้เปิดหน้าโปรโตคอล Then ต้องมีโปรโตคอลที่เสนอเพียงหนึ่งรายการเท่านั้น
- **AC-3** — Given limiting factor คือ Brain When ระบบเลือกโปรโตคอล Then โปรโตคอลที่เสนอต้องเป็นรายการที่จัดอยู่ในหมวด Brain ไม่ใช่หมวดอื่น

#### FR-29 (สูง) — บันทึกการทำโปรโตคอล
- **AC-1** — Given ผู้ใช้เริ่มตัวจับเวลาของโปรโตคอล When ตัวจับเวลานับจนครบเวลา Then ระบบบันทึกว่าทำโปรโตคอลแล้วโดยอัตโนมัติ โดยผู้ใช้ไม่ต้องกดยืนยันเพิ่ม
- **AC-2** — Given ผู้ใช้เลือกข้ามโปรโตคอลของวันนี้ When กดปุ่มข้าม Then ระบบบันทึกสถานะข้ามพร้อมวันที่
- **AC-3** — Given ผู้ใช้เริ่มตัวจับเวลาแล้วหยุดกลางคัน When ออกจากหน้าจอ Then ระบบต้องไม่บันทึกว่าทำแล้ว

#### FR-30 (สูง) — แสดงผลต่างของคะแนนวันถัดไป
- **AC-1** — Given ผู้ใช้ทำโปรโตคอลของหมวดใดหมวดหนึ่งเมื่อวาน When เปิดแอปในเช้าวันถัดไป Then ระบบแสดงผลต่างของคะแนนหมวดนั้นเทียบกับวันก่อนหน้า
- **AC-2** — Given ผู้ใช้มีทั้งวันที่ทำและวันที่ข้ามโปรโตคอลเดียวกัน When เปิดดูผลของโปรโตคอลนั้น Then ระบบแสดงการเปรียบเทียบระหว่างสองกลุ่มวัน

#### FR-31 (กลาง) — สรุปโปรไฟล์การตอบสนองรายบุคคล
- **AC-1** — Given ผู้ใช้มีข้อมูลการทำโปรโตคอลถึงเกณฑ์ขั้นต่ำที่กำหนด When เปิดหน้าสรุปโปรโตคอล Then ระบบแสดงว่าโปรโตคอลใดสัมพันธ์กับคะแนนที่ดีขึ้นมากที่สุดสำหรับผู้ใช้คนนี้
- **AC-2** — Given ข้อมูลยังไม่ถึงเกณฑ์ขั้นต่ำ When เปิดหน้าสรุปโปรโตคอล Then ระบบแจ้งว่ายังสรุปไม่ได้พร้อมระบุว่าต้องเก็บข้อมูลอีกเท่าใด

## 8. สรุปรายสัปดาห์และการส่งออกข้อมูล

#### FR-32 (กลาง) — หน้าสรุปรายสัปดาห์
- **AC-1** — Given ผู้ใช้มีข้อมูลครบอย่างน้อยหนึ่งสัปดาห์ When เปิดหน้าสรุปรายสัปดาห์ Then ระบบแสดงแนวโน้มของทั้ง 6 หมวด ยอดสะสมสปาร์ริง และอัตราการทำโปรโตคอลของสัปดาห์นั้น

#### FR-33 (ต่ำ) — ส่งออกข้อมูลของตนเอง
- **AC-1** — Given ผู้ใช้เลือกช่วงเวลาที่ต้องการส่งออก When กดส่งออก Then ระบบสร้างไฟล์ที่มีเฉพาะข้อมูลในช่วงเวลาที่เลือก

## 9. พื้นฐานระบบ: ความเร็ว ความปลอดภัย และการเข้าถึง

#### NFR-01 (สูง) — เวลากรอกข้อมูลรวมไม่เกิน 90 วินาทีต่อวัน
- **AC-1** — Given ผู้ใช้ที่คุ้นเคยกับแอปแล้ว When ทำการบันทึกข้อมูลครบทุกอย่างของหนึ่งวัน (เช็กอินเช้า บันทึกเซสชัน บันทึกอาหาร และการทดสอบที่กำหนดของวันนั้น) Then เวลารวมที่จับได้ต้องไม่เกิน 90 วินาที
- **AC-2** — Given ผู้ใช้อยู่ในช่วง Off-camp When เปิดแอปเพื่อเช็กอิน Then จำนวนคำถามที่ระบบถามต้องน้อยกว่าช่วง Weight cut

#### NFR-02 (สูง) — เข้ารหัสข้อมูลสุขภาพขณะส่งและจัดเก็บ
- **AC-1** — Given ระบบส่งข้อมูลสุขภาพระหว่างอุปกรณ์กับเซิร์ฟเวอร์ When ตรวจสอบการเชื่อมต่อ Then การรับส่งต้องผ่านช่องทางที่เข้ารหัส
- **AC-2** — Given ข้อมูลสุขภาพถูกจัดเก็บในฐานข้อมูล When ตรวจสอบข้อมูลที่จัดเก็บ Then ต้องอยู่ในรูปแบบที่เข้ารหัส

#### NFR-03 (สูง) — นักกีฬาเป็นเจ้าของข้อมูล
- **AC-1** — Given ผู้ใช้ยังไม่ได้ให้ความยินยอม When ระบบจะเปิดเผยข้อมูลให้บุคคลที่สาม Then ระบบต้องไม่เปิดเผยและต้องขอความยินยอมอย่างชัดแจ้งก่อนทุกครั้ง
- **AC-2** — Given ผู้ใช้ขอลบบัญชี When ยืนยันการลบ Then ระบบต้องลบข้อมูลสุขภาพทั้งหมดของผู้ใช้คนนั้น

#### NFR-06 (กลาง) — บันทึกแบบออฟไลน์แล้วซิงก์ภายหลัง
- **AC-1** — Given อุปกรณ์ไม่มีสัญญาณเครือข่าย When ผู้ใช้บันทึกเซสชันซ้อม Then ระบบบันทึกลงเครื่องได้สำเร็จและแสดงสถานะรอซิงก์
- **AC-2** — Given มีข้อมูลรอซิงก์อยู่ When อุปกรณ์กลับมาออนไลน์ Then ระบบซิงก์ข้อมูลโดยอัตโนมัติโดยผู้ใช้ไม่ต้องสั่ง

#### NFR-07 (กลาง) — พื้นที่แตะ 44×44 pt และคอนทราสต์ 4.5:1
- **AC-1** — Given ผู้ใช้เปิดหน้าจอใดก็ตาม When วัดขนาดพื้นที่แตะขององค์ประกอบที่กดได้ทุกชิ้น Then ต้องไม่เล็กกว่า 44×44 pt
- **AC-2** — Given ผู้ใช้เปิดหน้าจอในธีมสว่างและธีมมืด When วัดอัตราคอนทราสต์ของข้อความทุกชิ้นกับพื้นหลัง Then ต้องไม่ต่ำกว่า 4.5:1 ในทั้งสองธีม

#### NFR-09 (ต่ำ) — รองรับภาษาไทยและอังกฤษ
- **AC-1** — Given ผู้ใช้อยู่ในหน้าตั้งค่า When สลับภาษาระหว่างไทยกับอังกฤษ Then ข้อความทั้งหมดในแอปเปลี่ยนภาษาโดยไม่ต้องติดตั้งใหม่
