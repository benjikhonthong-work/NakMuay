## เงื่อนไขตั้งต้นร่วมของทุก test case

1. มีบัญชีทดสอบที่มีโปรไฟล์และ fight camp ครบแล้ว ([[acceptance-criteria#FR-01 (สูง) — สร้างโปรไฟล์นักมวย|FR-01]], [[acceptance-criteria#FR-02 (สูง) — สร้าง fight camp|FR-02]])

3. อุปกรณ์สวมใส่ซิงก์ข้อมูลของคืนที่ผ่านมาเรียบร้อยแล้ว ([[acceptance-criteria#FR-05 (สูง) — เชื่อมต่ออุปกรณ์สวมใส่|FR-05]])
