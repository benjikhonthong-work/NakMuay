## 3. Environment

**ยังกำหนดไม่ได้ในขณะนี้** — `docs/02-design/02-technical/technology-stack.md` ยังว่างเปล่า
จึงยังไม่มีการตัดสินใจเรื่องแพลตฟอร์ม เฟรมเวิร์ก หรือฐานข้อมูล

สิ่งที่ทราบแล้วจาก spec และนำมากำหนดเป็นเงื่อนไขของ environment ได้:

| ประเด็น | สิ่งที่ทราบแล้ว |
|---|---|
| อุปกรณ์ | โทรศัพท์มือถือของผู้ใช้ ต้องเชื่อมต่ออุปกรณ์สวมใส่ได้ |
| ข้อมูลนำเข้าภายนอก | HRV ชีพจรขณะพัก และข้อมูลการนอน จากอุปกรณ์สวมใส่ ([[20260828-01-boxer-recovery-tracking#3.2 การเชื่อมต่ออุปกรณ์และ baseline\|FR-05]]) |
| สภาวะเครือข่าย | ต้องทดสอบทั้งออนไลน์และออฟไลน์ ([[20260828-01-boxer-recovery-tracking#4. ความต้องการที่ไม่ใช่เชิงฟังก์ชัน\|NFR-06]]) |
| ธีม | ต้องทดสอบทั้งธีมสว่างและธีมมืด ([[20260828-01-boxer-recovery-tracking#4. ความต้องการที่ไม่ใช่เชิงฟังก์ชัน\|NFR-07]]) |
| ข้อมูลทดสอบ | ต้องมีบัญชีที่มี baseline ครบ 14 วันแล้ว และบัญชีที่ยังเก็บ baseline ไม่ครบ |

ต้องกลับมาเติมหัวข้อนี้ให้ครบเมื่อ `technology-stack.md` ถูกตัดสินใจแล้ว

## 4. Entry Criteria

1. `feature-list.md` และ `user-journey.md` สอดคล้องกับ `backlog.md` ครบทุกรหัส
2. `acceptance-criteria.md` มี AC ครบทุกรหัส FR/NFR ที่จะทดสอบ
3. มีบัญชีทดสอบที่มี baseline ครบแล้วอย่างน้อยหนึ่งบัญชี
4. `technology-stack.md` ถูกตัดสินใจแล้ว และตั้ง environment ตามข้อ 3 ได้จริง

## 5. Exit Criteria

1. Test case ของรหัสระดับ **สูง** ทุกข้อผ่านครบ 100 เปอร์เซ็นต์ ไม่มีข้อยกเว้น
2. Test case ของรหัสระดับ **กลาง** ผ่านไม่น้อยกว่า 90 เปอร์เซ็นต์
3. ไม่มีข้อบกพร่องระดับ Critical หรือ High ค้างอยู่
4. NFR-04 และ NFR-05 ผ่านการตรวจโดยผู้ตรวจที่เป็นมนุษย์ และไม่พบข้อความที่วินิจฉัยโรคหรือแนะนำวิธีรีดน้ำหนักแม้แต่ข้อความเดียว
5. NFR-01 ผ่านการจับเวลาจริงกับผู้ใช้อย่างน้อย 5 คน

> ข้อ 4 เป็นเกณฑ์ที่ห้ามผ่อนผัน — เป็นทั้งประเด็นความปลอดภัยของผู้ใช้และความรับผิดทางกฎหมาย
