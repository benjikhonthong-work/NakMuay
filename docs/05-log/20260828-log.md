## 14:xx — Design System

- สัมภาษณ์ผู้ใช้ตามขั้นตอนของ `design-system-writer`
- **คำตอบของผู้ใช้:** ธีมมืดเป็นหลัก · ฟอนต์ Bai Jamjuree + IBM Plex Sans Thai · ความหนาแน่นปานกลาง
  มุมโค้ง 12px · ฐานสไตล์เลือกจาก GSP preset **`nothing`** (OLED ดำ, instrument, แดงสัญญาณ, ไม่มีเงา)
- เขียน [[DESIGN]] ใหม่ทั้งไฟล์ **12 หัวข้อ** (§1–§11 ตามมาตรฐาน + §12 บันทึกการปรับจาก preset)
- **การปรับจาก preset ที่ต้องบันทึกไว้:**
  - ฟอนต์ต้นทาง (Space Grotesk / Space Mono / Doto) ไม่รองรับภาษาไทย → แทนด้วยคู่ที่ผู้ใช้เลือก
  - `#D71921` บนพื้นดำได้คอนทราสต์เพียง ~2.9:1 ใช้กับข้อความไม่ได้ → แยก `--signal-text` เป็น `#FF6B60`
  - `#666666` ได้ ~4.1:1 ต่ำกว่าเกณฑ์ → ปรับ `--text-3` เป็น `#8A8A8A`
- แก้ §1 ข้อ 3 ระหว่างทำ prototype: จาก "แดงหนึ่งจุดต่อหน้าจอ" เป็น **"แดงหนึ่งเรื่องต่อหน้าจอ"**
  เพราะหน้าแรกมีทั้งแถบ limiting factor และ pill "ควรงด" ที่มาจากปัญหาเดียวกัน
- **ค่าคอนทราสต์ทั้งหมดเป็นการประเมิน ยังไม่ได้วัดด้วยเครื่องมือ**
